### Data warnings

- **The Wikipedia barangay table is mislabelled.** https://en.wikipedia.org/wiki/Liloan,_Cebu labels a column "2024", but its values (for example Yati 27,367, Cabadiangan 1,982) add up to 118,753. That is the **2015** census total on citypopulation.de. Do not use that column as 2024 data.
- **The barangaydirectory.com 2024 figures are suspect.** They show tiny 2020→2024 changes for the large barangays (Yati +36, Tayud +6) and large ones for small barangays (Cabadiangan +335). The municipal total rose 5,190. Use PSA 2024 POPCEN barangay tables when they are available.
- **Every captain name rests on one third-party directory,** and it was reached only through search-engine summaries (the site returned HTTP 503 `DEPLOYMENT_PAUSED`). Search summaries can garble text. Confirm each name with the Liloan municipal hall, DILG Cebu, or the LGU's FB page before publishing.
- The site's current markup (`public/government/index.html`, near line 973: "Barangays of Solano", 22 `barangay-name`/`barangay-captain` entries) is all Solano data and needs a full replacement with the 14 entries above.
